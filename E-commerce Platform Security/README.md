# Secure User Authentication System

## Overview

This project implements a secure user authentication system using Python, Flask, and SQLite. It demonstrates the fundamentals of secure web application development by providing user registration, authentication, and database management while following good security practices.

---

## Features

- User registration and login system.
- Secure password storage using password hashing.
- SQLite database for storing user credentials.
- Database schema initialisation using SQL scripts.
- Flask-based web application architecture.
- Modular project structure for maintainability and future development.

---

## Repository Structure

### Main Files

| File | Description |
|------|-------------|
| **app.py** | Main Flask application containing the authentication logic and application routes. |
| **init_db.py** | Initialises the SQLite database and creates the required tables. |
| **schema.sql** | SQL schema defining the database structure used by the application. |

## Project Objective

This project aimed to develop a secure authentication system that allows users to register and log in while protecting sensitive information through secure password storage and proper database management. The project demonstrates fundamental web security principles and secure software development practices.

---

## Results

The completed application successfully provides user authentication using a Flask web application connected to an SQLite database. Passwords are securely stored using hashing techniques, and the modular structure allows the application to be extended with additional security features.
