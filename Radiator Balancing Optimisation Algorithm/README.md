# Can an Algorithm Predict the Correct Adjustment to Lock Shield Positions for Each Radiator Simultaneously to Balance a Building?

## Overview

This project investigates whether an algorithm can accurately predict the required lock shield valve adjustments for every radiator in a heating system simultaneously, allowing a building to be hydraulically balanced more efficiently than traditional manual methods.

---

## Features

- Predicts optimal lock shield valve positions for multiple radiators simultaneously.
- Simulates radiator balancing using an optimisation algorithm.
- Stores and loads test data using JSON.
- Modular program structure allowing further development and testing.
- Includes previous development versions to demonstrate the project's evolution.

---

## Project Objective

This project aimed to determine whether an optimisation algorithm could accurately predict the correct lock shield valve positions required to hydraulically balance an entire heating system simultaneously.

The system analyses radiator performance and calculates valve adjustments intended to improve heat distribution throughout a building while reducing the need for manual trial-and-error balancing.

---


## Results

Testing demonstrated the effectiveness of the optimisation algorithm in predicting lock shield valve adjustments.

The accompanying `RadiatorBalancingData.json` file contains the experimental data used during evaluation.
